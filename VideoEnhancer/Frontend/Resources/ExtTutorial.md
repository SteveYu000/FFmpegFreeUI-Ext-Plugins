## Ext 版补充（0.1.0）

上面的原文适合了解模型、推理后端、超分、补帧和 HDR。Ext 版的入口、安装与任务方式有所调整，操作时请以本节为准。

### 安装与更新

关闭宿主，将完整 ZIP 解压到宿主的 `Plugin` 目录。主插件文件为 `videoenhancer.ext.3fui.dll`；若仍有旧的 `videoenhancer.3fui.dll`，删除旧文件。模型和配置目录应保留。Ext 版仅发布 ZIP，没有 EXE 安装包或独立 CLI。ZIP 内附有中文安装说明和 FFF.Native 预览组件。预览还需要 FFmpeg Shared 库；该库以及 Python/RVE、RTX 运行组件和模型在模型下载页按需安装。

### 开关、参数与预设

“参数面板 → 画面帧下方 → 视频参数 | AI增强”提供超分、补帧、HDR 和分段开关，分别控制对应功能。选择推理后端和模型后启用所需功能；RVE 超分与补帧都需选择对应模型。没有插件总开关。参数写入宿主参数总览，并随预设保存、恢复。AI 开关全部关闭且没有有效分段方案时，按宿主原参数处理。

“视频超分”是参数面板下方的独立入口，包含首页、实时预览、模型下载、模型转换、模型导入和使用教程。首页显示本插件任务状态、参数检查信息、已安装模型和 ZIP 更新信息。原文提到的图片超分、右键超分和独立分段标签页在 Ext 版中不提供。

### 运行视频任务

在宿主添加输入文件、配置参数并加入编码队列。插件从任务自己的预设快照读取设置，先处理选中的视频流，生成仅含视频的无损 FFV1/MKV 中间文件。宿主 FFmpeg 随后使用增强视频与原始音频、字幕、附件、章节和元数据，继续执行最终滤镜、编码、封装及后处理。

最终编码器、音频、字幕、输出容器和自定义 FFmpeg 参数仍在宿主参数面板设置。它们不直接传给 RVE；RVE 按插件生成的真实后端参数运行。RTX 的任务参数通过 HTTP JSON 发送，命令行用于启动服务；对应请求和命令可在参数总览及任务详情查看。排队之后修改面板设置不影响已排队任务。

### 分段超分

在准备文件页加入视频，启用“分段超分”并打开“编辑分段方案”，选择视频、计数模式和各段处理方式，再开启“此文件分段”。秒模式的断点吸附关键帧，也可使用精确帧。模型的固定倍率决定最终尺寸，FFmpeg/Anime4K 段跟随该尺寸。跨模型后端混用是测试选项，默认关闭。

仅对已配置且启用分段方案的输入应用分段；其余输入沿用普通超分、补帧和 HDR 设置。分段暂不能与补帧或 RTX HDR 同时开启。模型段仍需要对应运行组件与模型，FFmpeg 段可以用于不调用 AI 的缩放。

### 参数错误与任务状态

模型尚未选择、预设 JSON 无效或配置冲突时，插件在参数总览和首页显示错误，命令预览不启动后端。真实任务会在准备或启动进程前停止并记录原因；不会静默跳过已启用的 AI 增强。修改参数后重新排队或重置任务，再执行。

暂停、继续、停止和最终输出仍由宿主队列管理。双击首页任务可查看参数快照和真实后端命令。任务结束后插件清理自己的临时视频，模型与配置保留。
