# FFmpegFreeUI-Ext-Plugins

## 插件目录

- [ab-av1](./ab-av1/README.md)——插件使用了AB-AV1的功能，计算目标VMAF或者xpsnr分数所需的最小crf值。
- [VideoEnhancer](./VideoEnhancer/README.md)——视频 AI 增强插件，基于[maxzrb](https://github.com/maxzrb/VideoEnhancer)版本修改
