# AB-AV1 插件更新日志

## 1.0.1 - 2026-09-21

### 修复

- 修复选择“使用目标分数（ab-av1）”后再切换回原生 CRF 模式时，参数预览仍显示 AB-AV1 插件自定义参数的问题。
- AB-AV1 参数现在只会在插件模式启用时显示；切换回原生模式不会清空已经保存的搜索设置，再次启用插件时仍可继续使用原设置。

### 兼容性

- 安装要求保持不变：需要 Ext Plugin API 2.5.0 或更高版本、Windows 10/11 和 .NET 10 Desktop Runtime。
- 本次更新不改变预设数据格式，无需迁移现有预设。

### 升级方式

关闭 FFmpegFreeUI 后，使用 v1.0.1 的 `FFmpegFreeUI.Ext.AbAv1.3fui.dll` 替换插件目录中的旧版本文件即可；`ab-av1.exe` 无需因本次修复而更新。
